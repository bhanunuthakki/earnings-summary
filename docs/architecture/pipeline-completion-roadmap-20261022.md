## Review rule

Use a fresh-context GPT-6.1 reviewer that did not implement the stage. Supply the
artifact, raw evidence and this rubric, without a suggested grade. Score source
scope and completeness (20), lineage and semantic correctness (25), execution
correctness (20), recovery and isolation (15), verification (10), and reuse and
maintainability (10). Require more than 90/100, no unresolved blocking finding,
and all required deterministic gates. Fix findings and review the changed
artifact again. A score cannot waive a failed test or authorize a new effect.
These are task-specific independent reviews, not calibrated governance receipts.
No review score or completed stage is claimed before the evidence exists.

Worker boundaries: one Sol worker owns the bulk CLI and its tests; a separate
worker owns direct supplement continuation after the plan review. The root owns
documentation, integration, operational evidence and final acceptance. A fresh
GPT-6.1 seat reviews each major stage. Direct pytest runs stay serial. Chisle
means focused searches, small reads, existing owners and no added dependency
when installed tools suffice. Do not add a second tracking or audit system.

## PDF provider decision — verified 2026-10-23

Keep retained native text and table evidence as the first path. The two retained
META PDFs supplied 11 nonblank native pages; the frozen sample has 44 expected
facts. No OCR failure was observed in that sample. Nonblank text alone does not
prove that every visual fact was extracted. Run the bounded model pilot before
adding a paid document adapter.

OpenRouter supports native PDF input and the `file-parser` plugin. Its current
engines include `cloudflare-ai`, `mistral-ocr` and `native`; `pdf-text` is deprecated.
Without an explicit engine, a non-native route can select billed Mistral OCR.
The OCR path forwards at most eight images per PDF/request. Reused file
annotations can avoid repeated parsing. These facts support explicit engine and
page scope, rather than sending an entire archive through an implicit default.
Source: [OpenRouter PDF inputs](https://openrouter.ai/docs/guides/overview/multimodal/pdfs).

Mistral's OCR API exposes structured tables, page content, bounding boxes and
confidence information. Table formatting needs OCR 2512 or later; block extraction
needs OCR 4 or later. This is a candidate for measured image-only or table-layout
failures, not evidence that it improves this corpus. Source:
[Mistral OCR](https://docs.mistral.ai/studio/document-processing/basic_ocr).

For a future bounded comparison, submit the exact retained bytes and preserve
page/render/parser identity, costs, raw output and adjudicated source coordinates.
A live URL can return different bytes and is not the retained-source commitment.
The existing application adapter currently sends text; changing a model ID does
not add file input. Add such capability only behind that existing boundary after
a measured source failure and a useful comparison.

OpenRouter's documented server tools include web fetch and search; they are not
a ready-made IR browser runtime. A model can use application-provided browser
tools, but the application still owns navigation, bounds, source retention and
receipts. Recommendation: use the current discovery owner and feed/API/DOM paths;
add bounded browser recovery only for a demonstrated archive-navigation gap.
Source: [OpenRouter server tools](https://openrouter.ai/docs/guides/features/server-tools/overview).
