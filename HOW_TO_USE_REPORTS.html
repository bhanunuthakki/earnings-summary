Workspace reports

How to build, review, comment on, and refresh your research reports.

All commands work from any directory. The .bat launchers self-locate the repo, so you don't need to cd first. Just paste the full path into cmd.exe.

1. Quick start ¶

If you've used the system before and just want the muscle memory:

:: Terminal 1 — leave running
C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\start_comments_server.bat

:: Terminal 2 — build the report you want to read
C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\build_report.bat NU --enable-llm

:: Open the file in your browser
:: output\research\NU\<DATE>_workspace.html

:: Later — process anything you commented on
C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\process_comments.bat NU --apply

2. Daily workflow ¶

2.1 Build a report

C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\build_report.bat NU --enable-llm
  • --enable-llm runs the full pipeline (bear case, news, valuation, company description). Omit for a fast rebuild that reuses cached outputs.
  • Output lands at output\research\<TICKER>\<DATE>_workspace.html.

2.2 Start the comments + chat server

C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\start_comments_server.bat

Or just double-click start_comments_server.bat in Explorer.

  • Runs on http://localhost:7421
  • Keep the terminal open while reviewing
  • Ctrl+C to stop

2.3 Open the report in your browser

Open output\research\NU\<DATE>_workspace.html (double-click in Explorer, or drag into Chrome).

2.4 Comment on anything

Two ways to comment:

  • Structured anchors — hover over a KPI row, failure mode card, news item, valuation rationale, thesis lede, or company overview panel. A small + pin appears at the top-right corner. Click it.
  • Free-text (Google Docs style) — highlight ANY text in the report. A floating + Comment button appears below your selection.

Either way, the sidebar slides in from the right. Type your comment, optionally pick an intent (or leave on "Auto-classify"), click Post.

Status colors on the report:

  • Amber underline / pin = open
  • Green underline / pin = addressed

2.5 Chat with Claude about the report

Click the Chat button in the bottom-right corner. A Claude Sonnet 4.6 session opens with full report context loaded:

  • Your thesis, tier-1 KPIs, business-model rules
  • Bear-case failure modes + most-underweighted callout
  • Valuation multiple + rationale
  • Company description elevator pitch
  • Read-only filesystem access to data/, micro_thesis/, .tmp/, transcripts/ (so it can pull verbatim transcript quotes, look up segment numbers from FMP, etc.)

Type a question, press Cmd+Enter (or Ctrl+Enter) to send.

If you ask for an edit, the response includes a Preview / Apply button. Click Apply to write the change to disk.

2.6 Process comments

When you're ready to act on the comments you've left:

:: dry-run preview (default — won't touch files)
C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\process_comments.bat NU

:: actually mutate files (edits holdings JSON, runs LLM, etc.)
C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\process_comments.bat NU --apply

:: also drop addressed/dismissed comments after processing
C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\process_comments.bat NU --apply --clear

After processing, rebuild the report to see the updates:

C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\build_report.bat NU --enable-llm

Refresh the browser tab. Addressed comments turn green; their resolution notes + chat threads are visible when you click the highlight.

3. Slash-keyword shortcuts ¶

Prefixing a comment with one of these keywords sets the intent inline and skips both the dropdown and the Haiku auto-classifier. The keyword is stripped from the stored comment text.

PrefixRoutes toWhen to use
/kpidrop_kpiRemove a KPI you don't want to track anymore
/thesisedit_thesisModify the thesis paragraph
/updateedit_thesisSame as /thesis — incremental thesis edit
/qask_questionQuick question (short alias for /ask)
/askask_questionAsk Claude a question with full thesis + bear-case context
/fixfix_dataFlag a data error for manual fixing
/rewriterewrite_sectionBigger rewrite of the artifact this comment is on

Match rules:

  • Keyword must be at the start, no leading whitespace
  • Case-insensitive (/KPI works)
  • Optional : or space after (/ask: how does X work?)
  • Explicit dropdown picks always win

Examples:

/kpi SuperCore split made this irrelevant
/thesis revise to flag the FGTS regulation phasing
/q what's NU's NPL trend over the last 8 quarters?
/fix segments don't sum to total revenue
/rewrite this is too generic, focus on the cohort dynamics

How the processor handles each intent:

IntentWhat the processor does
drop_kpiRemoves the KPI from micro_thesis/holdings/<T>.json
edit_thesisAsks Opus to revise the thesis paragraph using your comment as guidance
ask_questionAsks Opus your question with the thesis + bear-case as context; reply lands in the comment's follow-up thread
fix_dataLogs a TODO line in directives/data_fixes.md for manual fixing
rewrite_sectionEmits cache-invalidation instructions for the targeted section
(blank)Haiku classifies into one of the above automatically

4. Refreshing data + regenerating reports ¶

When you want fresh inputs flowing into the report, run the relevant refresh in this order. Each step is independent — you can run any of them in isolation.

4.1 FMP financial data

Pulls income statement, balance sheet, cash flow, segments, ratios, key_metrics into data/historical/fmp/.

:: One ticker, last 8 quarters
refresh_fmp.bat NU

:: One ticker, deeper history
refresh_fmp.bat NU 20

:: All tracked tickers (uses FMP API quota)
refresh_fmp.bat --all

This is the source of truth for the Financials tab, valuation multiples, and DCF inputs.

4.2 Earnings-call transcripts

:: One ticker — pulls last 6 fiscal quarters from the free aggregator chain
:: (roic.ai → stockanalysis.com → tickertrends.io)
refresh_transcripts.bat NU

:: All active tickers
refresh_transcripts.bat --all

Drops new files into transcripts/processed/<T>_Q<n>_<YYYY>.txt and registers them in the transcripts table. Skips quarters where a file already exists.

For PDFs from IR (decks, press releases, etc.) Drop them in _inbox/ and run python execution\intake_documents.py --process. The intake classifier files them into ir_documents/<T>/<period>/ and chains into the LLM summarizer.

4.3 LLM-summarize the IR documents

python C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\execution\process_ir_documents.py --ticker NU

Reads each unprocessed document, runs the LLM summarizer with the thesis + bear-case anchor block, writes:

  • .tmp/<T>_Q<n>_<Y>_summary.txt (transcripts)
  • .tmp/<T>_Q<n>_<Y>_press_release_summary.txt (press releases)
  • .tmp/<T>_Q<n>_<Y>_presentation_brief.txt (slide decks)

4.4 KPI extraction

python C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\execution\extract_kpis_from_summaries.py --ticker NU --source earnings --repo-root C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary

Reads the .tmp/<T>_*_summary.txt files, asks Haiku to extract values for each tier-1 KPI defined in micro_thesis/holdings/<T>.json, persists to kpi_facts.

No tracked KPIs in the rendered report? This step hasn't run yet. Run it after step 4.3 whenever you add quarters or change the tier-1 KPI list.

4.5 SayDo pairwise rebuild

python C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\execution\build_saydo_pairs.py --ticker NU --repo-root C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary

Walks per-quarter summaries chronologically and generates one SayDo_<T>_Q<prev>_Q<curr>.txt per pair. Idempotent. Pass --refresh to force-regenerate every pair (after a prompt change).

4.6 News (force-refresh §News tab)

:: Default 7-day lookback
refresh_news.bat NU

:: 14-day lookback
refresh_news.bat NU 14

:: Refresh news for everyone tracked
refresh_news.bat --all-tracked

Bypasses the 7-day cache, runs Claude WebSearch + WebFetch with the thesis anchor so every news item names which tier-1 KPI it touches. Regenerates the workspace report wholesale.

4.7 Rebuild with refreshed LLM calls

:: Workspace renderer + full LLM pipeline
build_report.bat NU --enable-llm

:: Fast rebuild — reuse cached LLM outputs (just re-renders HTML)
build_report.bat NU

Cache invalidation by deletion — to force a specific section to re-run, delete its cache file and rebuild with --enable-llm:

4.8 One-button full refresh

full_refresh.bat NU

Runs all 6 steps in sequence: FMP → transcripts → IR doc processing → KPI extraction → SayDo pairs → workspace report with --enable-llm. Takes 5-15 minutes per ticker. Each step is independent — a failure in one doesn't kill the rest.

6. Reading the workspace report ¶

6.1 Tab walkthrough

Tab order for portfolio + watchlist tickers:

  1. Thesis — your investment case + tier-1 KPI status + break-rule evaluation. Start here on a known name. The thesis lede is at the top under the identity strip; it's commentable.
  2. Earnings — per-quarter analytical notes (newsletter-style, ordered newest-first). Quarter selector to scrub through historical prints. Q&A roster below each card.
  3. News — last 7 days of material developments, ranked by thesis impact. Every item names which tier-1 KPI it touches.
  4. Say · Do — print-vs-guide for the most recent quarter pair + verdict bar showing trajectory of last N quarters' attribution.
  5. Financials — 12-quarter YoY% matrix for line items, segments, geographies, OI, tracked KPIs + 12Q level table with segment drill-down.
  6. Valuation — Opus picks one diagnostic multiple per ticker; shows current value, 12Q sparkline, range, rich/cheap verdict, rationale.
  7. Bear case — most_underweighted callout + named failure modes. Each card has Evidence / Leading indicator / Quant impact / Refutation.
  8. Company — analytical business overview + revenue mechanics + segments + geographies + IR doc summaries.
  9. Position (only when held) — your shares, cost basis, P&L, recent transactions, open vs closed decisions.
  10. Sources — coverage matrix, validation issues, source-doc audit.

Evaluation flavor leads with Company instead of Thesis (you're new to the name) and adds an Eval Screen tab with the 3y quick-categorization data table.

6.2 Editing your thesis

The thesis is the single source of truth for everything downstream (KPIs, break rules, LLM prompt anchors, valuation multiple selection, bear case grounding).

micro_thesis/holdings/<TICKER>.json

Key fields:

  • thesis — free-text paragraph (the lede shown on every tab)
  • verdict — intact / watch / broken / pending (drives badge color)
  • key_driver — one-line "what I'm watching"
  • tier_1_kpis — list of {name, break_condition, source, ...}
  • business_model_rules — quantitative tripwires with narrative, kpi_name, comparator, threshold, unit, consecutive_periods
  • qualitative_breakers — soft risks
  • competitive_watchlist — rivals to monitor
  • valuation_multiple_override (optional) — pin one of the 10 allowed multiples

After editing, rebuild with --enable-llm to flow the change through:

  • Bear case re-grounds on the updated thesis
  • News + per-quarter summaries re-injected with the updated anchor
  • Valuation multiple re-evaluated (delete data/valuation_basis/<T>.json first)
  • KPI ledger re-renders with new break conditions

7. Onboarding a new ticker ¶

  1. Create micro_thesis/holdings/<NEW_TICKER>.json (copy an existing one as template; NU.json for bank/fintech, GOOG.json for profitable platform)
  2. Add the ticker to tracked_companies: 
    python execution\onboard_ticker.py --ticker <NEW_TICKER> --list-type portfolio
    Or --list-type watchlist / evaluation / archived
  3. Pull FMP data: refresh_fmp.bat <NEW_TICKER> 20
  4. Pull transcripts: refresh_transcripts.bat <NEW_TICKER>
  5. Process IR docs: python execution\process_ir_documents.py --ticker <NEW_TICKER>
  6. Seed KPI definitions: python execution\seed_kpi_definitions.py
  7. Extract KPIs: python execution\extract_kpis_from_summaries.py --ticker <NEW_TICKER> --source earnings --repo-root <REPO>
  8. Build: build_report.bat <NEW_TICKER> --enable-llm

Or after steps 1-2, just: full_refresh.bat <NEW_TICKER>

8. Adding IR documents ¶

Two paths:

(a) Auto-classify from _inbox/

Drop the PDF in <REPO>/_inbox/ then:

python C:\Users\Bhanu\.gemini\antigravity\scratch\earnings-summary\execution\intake_documents.py --process

The intake classifier identifies ticker + period + doc-type, files into ir_documents/<T>/<period>/, registers in document_index.json, chains into the LLM summarizer.

(b) Manual registration

If a PDF is already filed but not in the index (e.g., bulk-imported from another source), reset its processed flag and re-run the summarizer. See execution/intake_documents.py for the registration helpers.

10. Comment hygiene ¶

  • Use the /-keywords aggressively — skipping the dropdown + Haiku classifier saves time and is more reliable
  • Comments are per-report (per ticker+date). They don't carry across rebuilds with a new date. If a comment is important, address it before rebuilding.
  • Free-text highlights survive if the underlying text is unchanged. When you edit the company overview or thesis, old highlights on the changed text silently drop (the comment stays in the JSON store).
  • Run process_comments.bat <T> in --dry-run mode first to preview what each intent will do, then re-run with --apply when satisfied.

11. Subscription vs API billing ¶

The Claude CLI honors whichever auth is configured:

  • ANTHROPIC_API_KEY set in env → API metered billing
  • claude auth login + no ANTHROPIC_API_KEY → Pro/Max subscription

For this repo, API key is the documented default. You don't need to unset it. Cron jobs and .bat launchers all route through the same llm_client.py wrapper.

12. Pinning a specific valuation multiple ¶

The valuation tab lets Opus pick the diagnostic multiple per ticker. To override, add valuation_multiple_override to micro_thesis/holdings/<T>.json:

{
  "ticker": "NU",
  "valuation_multiple_override": "P/E (NTM)",
  ...
}

Allowed values: EV/NTM Revenue, EV/LTM Revenue, EV/NTM EBITDA, EV/LTM EBITDA, P/E (NTM), P/E (LTM), P/B, P/TBV, P/FCF, EV/FCF.

Delete data/valuation_basis/<T>.json and rebuild with --enable-llm to pick up the change.

14. Troubleshooting ¶

python: can't open file '...\execution\comments_server.py' You're trying to run the bare execution/... path from C:\Users\Bhanu. Use the .bat launchers — they self-locate the repo.
'#' is not recognized as an internal or external command # is a bash comment marker. cmd.exe doesn't understand it. Skip any line starting with # when copying from chat. cmd uses :: for comments.
Server unreachable — chat / new comments don't work Make sure start_comments_server.bat is running in another window. Read-only comment display works without the server (existing comments + highlights show); posting new ones and chat need it.
Highlight didn't appear on a free-text comment The selected text either crosses an element boundary mid-selection (rare) or the underlying text changed since the comment was posted. The comment stays in the store — look in data/report_comments/<T>/<DATE>.json.
Tracked KPIs are empty in the report Run the KPI extractor: python execution\extract_kpis_from_summaries.py --ticker <T> --source earnings --repo-root <REPO>
