## 2. What worked in the new principles

Concrete evidence from the 7 outputs:

### 2.1 Source-citation discipline held across all 7 reports
Every numeric KPI value, dated event, and management quote carries an inline source tag of the form `[Source: <doc>, <period>, <section>]`. Spot-checked NVO and MELI reports: zero unsourced numeric claims. Even the BN report under stale-corpus conditions cites the AGM page or Investor Day section name for every commitment.

### 2.2 `[not disclosed]` was used appropriately, not avoided
- **VEEV**: 3 cells (gross retention; competitor watchlist for Certara, Medidata)
- **NVO**: Wegovy standalone US sales (not broken out); compounding-pharmacy quantification; Q4-specific restructuring charge
- **MELI**: Specific Asian competitor names (Shein, TEMU not in 10-K text — only "Asian e-commerce platforms")
- **BN**: Heavy use — per-flagship subscription levels; per-Q carry; UK BWS acquisition counterparty/price; Oaktree-specific AUM; BEP/BIP standalone FFO
- **RBRK**: Total ARR Growth (RBRK doesn't report this metric)

The discipline visibly displaced the temptation to back-fill from prior-knowledge. NVO's report names the Annual Report's anonymized "Company A" as "plainly Lilly but not labeled" rather than just substituting Lilly silently — that's the right behavior.

### 2.3 Adversarial counters were name-specific, not generic macro
The "reject generic macro hand-waving" rule held best on the names where the LLM has the most context to draw on:
- **NVO** counters: Lilly tirzepatide TRx ratios (~469k vs Wegovy sc ~233k weekly), Wegovy pill week-3 ramp, CagriSema REIMAGINE 2/3 readouts, CMS CMMI Part D mid-2026, 340B $4.2bn provision reversal, $349 self-pay cut, FDA shortage list resolution
- **MELI** counters: Brazil free-shipping reset trade-off, Argentina FX exposure (41.6% direct contribution margin), Q4 ex-tax-credit underlying margin 8.9%, named Asian-entrant 10-K language
- **NU** counters: Mexico vs. Brazil mix effects, managerial-P&L methodology shift, Argentina funding cost spike
- **BN** counters: BWS asset target raise leans on UK M&A (organic CAGR drops 21%→17%); European waterfall recognition model invalidates literal $1B/Q carry threshold

No agent fell back on "macro could deteriorate" as a counter.

### 2.4 Conviction was calibrated honestly to corpus quality

The agents *named the reason* for the conviction cap each time. This is exactly what the prompt's "treat conviction as Low when source documents are sparse or stale" instruction was supposed to produce.

## 3. Prompt-tightening recommendations for the SDK migration

Six concrete patterns surfaced. All belong in the next iteration of `src/llm_client.py` `generate_thesis_update`.

### 3.1 [HIGH PRIORITY] Schema-vs-disclosure mismatch — systemic
**Confirmed across 3 of 7 holdings:**
- **NOW**: schema lists "Pro+ SKU Upsell Rate" — NOW does not disclose this metric. NOW publishes Now Assist >$1M ACV / >$5M ACV cohort proxies instead.
- **RBRK**: schema lists "Total ARR Growth" — RBRK only reports Subscription ARR and Cloud ARR, not a consolidated "Total ARR" line.
- **MELI**: schema lists "Credit NPL 90d+ >8% of portfolio" as a break threshold — MELI's stock 90d+ NPL is structurally 16-18% by definition. The threshold is permanently triggered; effectively non-actionable.

**Prompt fix:** Add an explicit instruction:
> If a Tier-1 KPI in the schema does not match a disclosed metric for this issuer, flag it as a first-class output in a new "Schema Hygiene" section (not in Analyst Notes). Name (a) the unmatched KPI, (b) the closest-disclosed proxy if one exists, (c) recommended threshold revision (e.g., flow metric instead of stock; named-proxy substitution). Do NOT score the unmatched KPI in the scorecard — emit `[schema mismatch — see Schema Hygiene]`.

**Schema fix (separate, longer-running):** All 11 holding JSONs need a one-time alignment pass against actual disclosure conventions per ticker. Suggest scaffolding a small `validate_holdings_schema.py` that reads each ticker's most recent IR docs and flags KPIs the issuer doesn't actually publish.

### 3.2 [HIGH PRIORITY] Stale-corpus template handling (BN signal)
When the corpus is materially stale (latest evidence >120 days old vs. report date), the standard "vs. Break Threshold" and "distance to break: X%" columns become category errors — the template forces precision the evidence can't support, and the analyst ends up disclaiming around the template in every cell.

**Prompt fix:** Detect staleness based on the most-recent `[Source: ...]` date in the corpus. If staleness >120 days:
- Replace "vs. Break Threshold" column with "vs. Latest Disclosed Forward Target" (compare current value to management's own forward commitment, not the schema's quantitative break)
- Add a required "Staleness Adjustment" line per scorecard row: "±X% uncertainty band reflecting Y quarters of unobserved drift"
- Cap all three loops' Net Conviction at Low unless the report explicitly justifies otherwise

This makes the BN-class output stop hand-waving and start producing structurally appropriate output.

### 3.3 [MEDIUM PRIORITY] Mid-year disclosure scope shifts (NU signal)
NU consolidated NPL geography mix and introduced a Managerial P&L mid-year, reducing Q-over-Q comparability for ARPAC, CTS, and Brazil-only NPL. The current prompt leaves it to analyst judgment to mention this; sometimes it gets buried in Analyst Notes.

**Prompt fix:** Add a required check:
> When comparing the same metric across two periods, verify methodology consistency. If the issuer disclosed a methodology change, footnote restatement, or scope expansion (different geographies, different revenue recognition, different segment definition), the comparability gap MUST be flagged at the cell where the comparison is made — not hidden in Analyst Notes. State the prior-method value, new-method value, and approximate delta attributable to methodology vs. underlying.

### 3.4 [MEDIUM PRIORITY] Inferred figures from FY-minus-period subtraction (NVO signal)
NVO's Q4-standalone metrics had to be inferred by FY25 minus 9M (e.g., 309 bDKK FY − 232 bDKK 9M ≈ 77 bDKK Q4 sales). The current prompt allows this, but the inference gets buried.

**Prompt fix:** Require an audit-trail source-tag format for any inferred values:
> `[Source: implied = FY25 AR p.16 minus Q3'25 deck p.17]` or equivalent. The provenance of inferred figures must be reproducible by the reader. Use `[implied]` as a doc_type marker so these are searchable separately from cited primary disclosures.

### 3.5 [MEDIUM PRIORITY] Pre-load prior-quarter snapshot for genuine numeric Say-Do (VEEV signal)
VEEV's Say-Do had Net Conviction = Low because the corpus had only Q4 FY26 docs — no prior-quarter guidance to verify against. The agent had to trust management's "exceeded guidance across the board" line as self-attestation.

**Pipeline fix (not pure prompt):** When a tracker run kicks off for a ticker, check `.tmp/extracted/` (or, post-SDK-migration, `.tmp/<ticker>_<prior-Q>_<prior-Y>_*.txt` cached summaries) for the immediately-prior quarter's docs. If present, load them as a "Prior-Q Guidance Reference" block in the prompt input, separate from "Current Period Evidence." This converts Say-Do from interpretive to mathematical.

For the session-mode demonstration, this would mean adding VEEV Q3 FY26 docs to the corpus before the next run. For the SDK pipeline, it's a one-time change to `update_thesis_tracker.gather_quarter_context()` to always include the prior period when scoring the latest.

### 3.6 [LOW PRIORITY] Ex-items adjustments — make required, not optional (MELI signal)
MELI agent voluntarily separated the $99mn Brazil tax credit from Q4 EBIT and reported underlying margin = 8.9% vs. headline 10.1%. This was not required by the prompt — it was the agent's own analytical instinct.

**Prompt fix:** Require explicit ex-items decomposition for any margin/EPS/FCF cell where the source document discloses a one-off (tax credit, restructuring, gain on sale, settlement, etc.). Format: "headline X% / underlying Y% (excluding $Zm <item> [Source: ...])". Otherwise the headline number can flatter the read.

## 4. Items NOT to change

The following held up well across the run and don't need the prompt to be tighter:

1. **Adversarial loop format** (Primary / Counter / Resolution+Conviction / Sensitivity) — produced consistent structure across 7 reports without any agent dropping a field.
2. **"Reject generic macro" instruction** — visibly displaced lazy counters; every loop sourced a name-specific challenge.
3. **`[not disclosed]` discipline** — used appropriately, not avoided. Even the most context-rich names (NVO, MELI) didn't try to back-fill from prior knowledge.
4. **Conviction H/M/L scale** — calibrated honestly across the corpus-quality spectrum (BN at L all the way to NU at H).
5. **Source-tag format** `[Source: <doc>, <period>, <section>]` — universally applied and traceable.
